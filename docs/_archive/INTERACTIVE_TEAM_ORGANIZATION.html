Key: Architect does NOT code features. Instead, architect reviews code for architectural soundness, challenges assumptions, catches technical debt early, and ensures decisions are documented.

How Architect Provides Oversight

📋 Code Review Flow
1
Engineer submits PR — Code + tests + ADR (if major decision)
2
Architect reviews — Checks canonical schema, no tight coupling, Phase 1.5 extensible, >80% coverage
3
If red flag — Stop work, team sync to resolve before merge
4
If good — Approve + merge, engineer closes PR
🎯 Architectural Decision Flow
1
Engineer proposes — "Should we use LSTM-VAE or XGBoost?"
2
Architect questions — "Why LSTM? What about latency? How does this scale?"
3
Team discusses — Tuesday sync, all perspectives heard, trade-offs explicit
4
Decision documented — ADR filed (context, decision, rationale, consequences, alternatives)
5
Architect approves — ADR merged to repo, team proceeds with confidence
🚨 What Architect Catches
🛑 Red Flags (Stop Work)
• Tight coupling between LSTM-VAE + Isolation Forest
• Schema can't scale to 5+ customers
• No monitoring configured
• Model checkpoint without metadata
• Secrets in code or config files
🟡 Warnings (Discuss Before Merge)
• Premature optimization without profiling
• Monolithic API endpoints
• Silent failures (missing sensors logged but model runs)
• Hard-coded thresholds instead of parameterized
• Code duplication
📅 Weekly Architecture Sync Details
When Tuesday 10 AM, 30 minutes
Who ML Engineer + Backend Engineer + DevOps + Architect
Format Standup (5 min) + Review (15 min) + Decisions (8 min) + Next Week (2 min)
Output Slack thread + ADRs filed + action items + tracker updated
📋 Agenda: Architecture Review (15 minutes)
1. Dependencies — Any new imports? Justified in ADR?
2. Schema — Database changes? Migration tested forward + rollback?
3. APIs — Contract changes? Breaking changes?
4. Errors — New failure modes identified? SLA impact?
5. Performance — Latency budgets met? Baselines hit?
6. Phase 1.5 — Ongoing readiness assessment
Why Tuesday? Allows Monday wrap-up, gives time to implement feedback Wed-Fri, and resets the week. Non-negotiable — team cannot move forward without weekly alignment.
